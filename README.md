# CP Market Stress & Working Capital Management

**Bachelor Thesis**

*How does stress in the non-financial commercial paper market influence firms' working capital management and supply-chain operations?*

---

## Structure

```
Analysis/
├── config.py          # Shared path configuration (DATA_DIR, OUTPUT_DIR)
├── notebooks/
│   ├── FRED.ipynb     # CP market data & stress index
│   ├── EDGAR.ipynb    # CP-issuer sample construction
│   ├── WRDS.ipynb     # Firm-level panel & control group
│   └── RESULTS.ipynb  # Final analysis, regressions & figures
├── data/              # Intermediate outputs (not tracked by Git)
└── output/            # Final charts and tables
```

## Notebook Order

The notebooks must be run in the following order, as later notebooks depend on outputs written to `data/` by earlier ones.

| # | Notebook | Data source | Key outputs in `data/` |
|---|----------|-------------|------------------------|
| 1 | `FRED.ipynb` | FRED API | `FR_master_aligned.csv`, `FR_csi.csv`, `FR_stress_episodes.csv` |
| 2 | `EDGAR.ipynb` | SEC EDGAR full-text search API | `ED_cp_final_sample.csv` |
| 3 | `WRDS.ipynb` | WRDS / Compustat (requires institutional access) | `WR_wc_panel_enriched.csv`, `WR_control_matches.csv`, `WR_cp_master_sample.csv` |
| 4 | `RESULTS.ipynb` | Outputs from all three above | Final figures and tables in `output/` |

`FRED.ipynb` and `EDGAR.ipynb` are independent of each other and can be run in either order. `WRDS.ipynb` requires only `EDGAR` output. `RESULTS.ipynb` requires all three.

## Setup

### Requirements

Dependencies are managed with [uv](https://docs.astral.sh/uv/). Two virtual environments are used:

- `venvs/default/` — used by `FRED.ipynb`, `EDGAR.ipynb`, and `RESULTS.ipynb`
- `venvs/wrds/` — used by `WRDS.ipynb` (requires the `wrds` Python package)

To recreate the environments:

```bash
# Default environment
uv sync --project venvs/default/pyproject.toml

# WRDS environment
uv sync --project venvs/wrds/pyproject.toml
```

### Environment variables

Create a `.env` file in the `Analysis/` directory with the following keys:

```
FRED_API_KEY=your_fred_api_key
WRDS_USERNAME=your_wrds_username
WRDS_PASSWORD=your_wrds_password
USER_AGENT=YourName/1.0 (your@email.com)
```

A FRED API key can be obtained for free at [fred.stlouisfed.org](https://fred.stlouisfed.org/docs/api/api_key.html). WRDS access requires an institutional subscription.

### Data directory

The `data/` folder is not tracked by Git. It is created automatically when `config.py` is imported. All intermediate files are generated by running the notebooks in order.
